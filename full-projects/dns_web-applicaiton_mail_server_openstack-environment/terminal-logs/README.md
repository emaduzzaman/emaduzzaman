# Terminal Logs

This folder contains the **command-line session logs** from the two virtual machines used in the project:

- **VM 1:** DNS server  
- **VM 2:** Web + Mail server  

These logs document the **exact commands executed** during configuration and testing.

---

## Files

| File | Description |
|------|-------------|
| [cli-dns-lab.md](cli-dns-lab.md) | Full terminal session for DNS server setup, zone configuration, and validation |
| [cli-web-mail.md](cli-web-mail.md) | Full terminal session for Web/Mail server setup, service verification, and connectivity tests |

## Purpose

- Provides a **reproducible record** of the configuration steps  
- Acts as a **technical reference** for deployment and testing
